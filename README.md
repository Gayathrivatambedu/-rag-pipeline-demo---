# 🧠 RAG Pipeline Demo  
Simple Retrieval‑Augmented Generation (RAG) pipeline using Python, LangChain, and ChromaDB.

This project demonstrates how to build a basic RAG workflow:
- Load documents  
- Chunk text  
- Create embeddings  
- Store in a vector database  
- Retrieve relevant chunks  
- Generate grounded answers using an LLM  

---

## 🚀 Tech Stack
- Python  
- LangChain  
- ChromaDB  
- Hugging Face / OpenAI Embeddings  
- FastAPI (optional extension)
